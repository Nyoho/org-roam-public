** PDFの各ページを同じサイズに整頓する

PDFの各ページを同じサイズに整頓する方法。

[[https://stackoverflow.com/questions/7446552/resizing-a-pdf-using-ghostscript][resize - Resizing a PDF using Ghostscript - Stack Overflow]] に書いてあったものを[[https://bugs.ghostscript.com/show_bug.cgi?id=705187][705187 – Ghostscript 9.56 removes hidden (e.g. OCR) text layers when refrying with NEWPDF=true]]により少し修正。

  #+begin_src shell
    gs \
        -o output.pdf \
        -sDEVICE=pdfwrite \
        -sPAPERSIZE=a4 \
        -dFIXEDMEDIA \
        -dPDFFitPage \
        -dCompatibilityLevel=1.6 \
        -dEmbedAllFonts=true \
        -dNEWPDF=false \
        input.pdf
  #+end_src
