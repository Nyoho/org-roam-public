#+title: whisper

OpenAIのWhisper
https://github.com/openai/whisper

かなりいい感じの文字起こしモデル。

* whisper.cpp
その C++ port。

https://github.com/ggerganov/whisper.cpp → https://github.com/ggml-org/whisper.cpp

READMEの通りにモデルをダウンロード。大きいモデルはさすが精度が高い。

** コンパイル方法
#+begin_src shell
  cmake --build --config Release
#+end_src

** 実行例

16-bit WAV がない場合は作る。input.mp3 から output.wav を作る例。

#+begin_src shell
 ffmpeg -i input.mp3 -ar 16000 -ac 1 -c:a pcm_s16le output.wav
#+end_src

audio.wav を文字起こしする例

 #+begin_src shell
 ~/ghq/github.com/ggerganov/whisper.cpp/build/bin/whisper-cli  --language ja -ovtt -osrt -m ~/ghq/github.com/ggerganov/whisper.cpp/models/ggml-large-v3-turbo-q8_0.bin -f audio.wav
 #+end_src

#+begin_src shell
./build/bin/whisper-cli --language ja -ovtt -osrt -m ./models/ggml-large-v3-turbo-q8_0.bin -f ~/prog/inputfile.wav
#+end_src

** Core ML で使うには
https://github.com/ggerganov/whisper.cpp#core-ml-support


** whisper-stream
streamで使うには whisper-stream。

#+begin_src sh
  ~/ghq/github.com/ggerganov/whisper.cpp/build/bin/whisper-stream \
     --step 500 \
     --length 5000 \
     --keep 200 \
     --language en \
     --flash-attn \
     -m ~/ghq/github.com/ggerganov/whisper.cpp/models/ggml-large-v3-turbo-q8_0.bin
#+end_src
