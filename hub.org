GitHub 用の hub コマンド

[[https://github.com/github/hub][github/hub]]

[[http://hub.github.com/][hub · the command-line wrapper for git]]

自分のプロジェクト hoge を clone
#+BEGIN_SRC sh
hub clone hoge
#+END_SRC

他人 jony のプロジェクト hoge を clone
#+BEGIN_SRC sh
hub clone jony/hoge
#+END_SRC
