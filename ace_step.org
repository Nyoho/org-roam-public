ACE-Step-1.5 を隣にclone。そこで、

#+begin_src sh
uv run acestep --port 8001 --enable-api --backend pt --server-name 127.0.0.1
#+end_src

UIは ./server と . でそれぞれ ~npm run dev~ を起動する。


* 既存の曲のアレンジ
1. generation mode を remix
2. source audioをアップロード
3. Editをチェックし、source captionとsource lyricsを入力
4. Remix strength, cover strength (melogy retention)を調整する。
   - conver strength は小さいと保持しない。大きいと元を保持する
   - remix strength は小さいとクリエイティブに自由。高いとオリジナルに近くなる。
