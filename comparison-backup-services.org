バックアップサービスの比較

* PostgreSQLのローカルバックアップを完全に外にバックアップしたい。

- [[https://aws.amazon.com/jp/ebs/][Amazon Elastic Block Store (EBS)]] (AWS)
- [[https://aws.amazon.com/jp/s3/pricing/][Amazon S3]] (AWS)
- [[https://aws.amazon.com/jp/s3/reduced-redundancy/][Amazon S3 低冗長化ストレージ]] (AWS)
- [[https://dumper.io/][Dumper: Database Backup for Rails]]
- [[https://cloud.google.com/storage/pricing?hl=ja][Google Cloud Storage (Google Cloud Platform)]]

を比較する。

容量に寄るけど1GBぐらい使ったとしたら

|                   | EBS gp2 | EBS st1 | EBS sc1 |    S3 | Dumper | GCS 日本 |
| 1GBあたり(米ドル) |     0.1 |   0.045 |   0.025 | 0.023 |    0.3 |    0.023 |


- gp2 = General Purpose SSD
- st1 = Throughput Optimized HDD
- sc1 = Cold HDD
- GCS 日本 = Google Cloud Storage 日本リージョン (asia-northeast1)

[[https://aws.amazon.com/jp/rds/postgresql/][Amazon RDS for PostgreSQL]] はめちゃくちゃ便利だけど高いので却下した。
