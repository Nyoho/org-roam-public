* Basic
** Installation
#+BEGIN_SRC sh
gem install rspec
#+END_SRC

** Start
#+BEGIN_SRC sh
rspec --init
#+END_SRC

** Write spec

Assume a class Book is in lib/book.rb.

Write spec/lib/book_spec.rb as follows.
#+BEGIN_SRC ruby
  describe "spec_helper"

  describe "Book" do
    it "something" do
      book = Book.new
      expect(book.some_property).to eq 'Something'
    end
  end
#+END_SRC
