* Tips
** height

#+BEGIN_SRC css
height: 100%
#+END_SRC

のためには
#+BEGIN_SRC css
  html, body {
      height: 100%;
  }
#+END_SRC
をする。
html が height: auto になっているため。

** shape
ハートマーク切り取りができる。

#+begin_src css
  clip-path: shape(from 50% 91%,line to 90% 50%,arc to 50% 9% of 1%,arc to 10% 50% of 1%);
#+end_src

from [[https://codepen.io/t_afif/pen/LEEbdrw][Heart shape using shape()]]

** Compass

#+begin_src sh
compass create
#+end_src
で始める。

#+begin_src sh
compass watch
#+end_src

#+begin_src sh
compass compile
#+end_src


config.rb に

#+BEGIN_SRC ruby
require 'compass-h5bp'
# require 'html5-boilerplate'
require 'susy'
#+END_SRC

を追加した。
