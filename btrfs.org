* Commands
SSDには option ssd

#+begin_src sh
btrfs filesystem show
#+end_src

label や uuid などがわかる。


ラベルをつける

#+begin_src sh
btrfs filesystem label
#+end_src


一覧を出す。uuidやラベルやサイズなどが出てくる。

#+begin_src sh
btrfs filesystem show
#+end_src


デバイスのエラーなどを表示する。 =/dev/sda1= や =/mnt/foo= など

#+begin_src 
btrfs device stats /dev/sda1
#+end_src

** options
- subvol=subvolume-name :: subvolume-name という名前のサブボリュームをマウント
- compress=lzo :: 圧縮する。lzoで。
- autodefrag :: 自動デフラグ
- ssd :: SSDに優しい
- discard :: 解放されたブロックをトリムできるように
- inode_cache :: inodeの空き情報をキャッシュする

** mount

=/dev/sda1= の中にある =foo= という名前のsubvolumeをmountするには、

#+begin_src shell
  mount /dev/sda1 /somewhere -o subvol=foo
#+end_src

** restore
rsyncで
https://www.funtoo.org/BTRFS_Fun#Using_snapshots_for_system_recovery_.28aka_Back_to_the_Future.29

=/mnt= にコピー先 (リストア先) をマウントしておくとすると、

#+begin_src shell
rsync --progress -aHAX --exclude=/proc --exclude=/dev --exclude=/sys --exclude=/mnt --exclude=/home snapshots/root_last/* /mnt
#+end_src
