#+TITLE: Googleカスタム検索エンジン Google Custom Search Engine (CSE)

[[https://cse.google.com/][Googleカスタム検索エンジン (Google Custom Search Engine (CSE))]]

=cx= (Custom search engine ID) の見つけ方
[[http://ryutamaki.hatenablog.com/entry/2014/01/18/171640][google custom search engine(CSE)を使って、検索結果をjsonで取得する - ryutamaki]]
によると、詳細の「検索エンジン ID」をポチッとすると出る。

#+BEGIN_SRC 
https://www.googleapis.com/customsearch/v1?key={APIキー}&cx={ここにcxをかく}&q=cat
#+END_SRC

いつも通り https://console.cloud.google.com/iam-admin/projects でプロジェクトを作成して API key をゲットだぜする。
