https://github.com/ggreer/the_silver_searcher

高速な (=ack= より) grep のようなもの。
でもコマンド名は =ag=

* ファイルタイプを制限
#+BEGIN_SRC sh
ag --elisp setq
#+END_SRC
で .el のみ検索になる。
file type は
#+BEGIN_SRC sh
ag --list-file-types
#+END_SRC
で出ます。他にも =--html= などいろいろ。
