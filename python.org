* 等しいことを実装する
Python 3 ならもう =__eq__= のみ実装すればいいらしい。

#+BEGIN_SRC python
  class Hoge:
      def __eq__(self, other):
          """Overrides the default implementation"""
          if isinstance(other, Hoge):
              return self.something == other.something
          return False
#+END_SRC
