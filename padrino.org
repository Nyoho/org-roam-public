Padrino

レンダリングに slim を、CSS には sass を使うには、

#+BEGIN_SRC sh
padrino g project sample-padrino-static-pages --renderer slim --stylesheet sass
#+END_SRC

でよい。


#+BEGIN_SRC ruby
  set :static, true
  set :public_folder, 'public'
#+END_SRC
とすると静的ファイル配信が変更できる。
